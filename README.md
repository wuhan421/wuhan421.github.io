# WUHAN421 System Log

纯静态个人博客首页，可直接部署到 GitHub Pages。

## 本地预览

直接双击 `index.html` 即可打开。页面不依赖构建工具。

## 发布到 GitHub Pages

1. 在 GitHub 新建公开仓库 `wuhan421.github.io`。
2. 上传本目录中的 `index.html`、`styles.css` 和 `app.js`。
3. 打开仓库的 `Settings > Pages`。
4. 在 `Build and deployment` 中选择 `Deploy from a branch`。
5. Branch 选择 `main` 和 `/ (root)`，然后保存。
6. 等待约 1-3 分钟后访问 `https://wuhan421.github.io`。
