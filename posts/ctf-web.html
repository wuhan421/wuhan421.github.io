CTF Web 入门：从请求到漏洞定位

这是一套面向合法 CTF 环境的基础排查流程。目标不是盲目尝试，而是先建立请求、响应与服务行为之间的证据链。

01 // 建立基线

  1. 浏览所有公开页面，记录功能入口与参数。
  2. 打开开发者工具的 Network 面板，观察请求方法、状态码和响应类型。
  3. 重复一次正常操作，保存它作为后续对比的基线请求。

02 // 缩小范围

一次只改变一个输入。重点比较状态码、响应长度、跳转位置、错误信息与响应时间，避免多变量同时变化。

输入点 → 请求差异 → 服务响应 → 可重复验证 → 复盘记录

03 // 记录结果

每条记录至少包含目标、原始请求、修改内容、实际响应和结论。未验证的猜测与已确认的行为要明确分开。
