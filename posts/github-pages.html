GITHUB // FIELD LOG 002

GitHub Pages 部署记录

使用一个公开仓库托管静态页面，不需要购买服务器，也不需要保持电脑开机。

01 // 仓库

个人主页仓库使用固定名称 wuhan421.github.io。把入口文件命名为 index.html 并放在仓库根目录。

02 // Pages 设置

  1. 进入仓库的 Settings → Pages。
  2. Source 选择 Deploy from a branch。
  3. Branch 选择 main，目录选择 /(root)。
  4. 保存并等待部署完成。

03 // 更新

以后每次修改并提交文件，GitHub Pages 都会自动重新发布。若页面没有更新，先检查 Actions 中的部署记录，再强制刷新浏览器缓存。
