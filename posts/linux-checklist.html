LINUX // FIELD LOG 003

终端命令与排错清单

先确认环境，再确认网络，最后确认应用。按层排查能够避免把认证问题误认为网络故障。

01 // 环境

pwd
whoami
uname -a
ip addr
ip route

02 // 网络

getent hosts example.com
ping -c 4 example.com
curl -I https://example.com
ss -lntup

03 // 判断

  • 域名无法解析：先检查 DNS。
  • 地址可达但端口关闭：检查服务与防火墙。
  • 协议握手成功但登录失败：检查账号、密钥和权限。
